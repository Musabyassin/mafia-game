# 🕵️ لعبة المافيا

لعبة مافيا جماعية (خداع واستنتاج) بنفس سياسة لعبة **سيد العقار**: غرفة بكود من 4 أرقام، شاشة تلفاز للعرض، وكل لاعب يتحكم من هاتفه — ودوره سري لا يراه غيره.

## طريقة اللعب
1. افتح `/tv/` على التلفاز أو الحاسوب — تنشأ غرفة ويظهر كودها ورمز QR.
2. كل لاعب يفتح `/play/` على هاتفه، يدخل الكود واسمه (5–12 لاعباً، ويمكن للمضيف إضافة لاعبين آليين).
3. المضيف يضبط الخيارات (إظهار دور الميت، سرعة اللعبة) ويضغط «ابدأ».
4. تُوزع الأدوار سراً: 🔪 مافيا، 💉 طبيب، 🔎 محقق، 🧑 مواطنون.
   - **الليل:** المافيا تختار ضحية (ولها شات سري)، الطبيب يحمي لاعباً، المحقق يتحقق من لاعب.
   - **النهار:** نقاش واتهامات (شات عام يظهر على التلفاز)، ثم تصويت لإقصاء مشتبه به — التعادل يعني لا إقصاء.
   - **الفوز:** الأبرياء بإقصاء المافيا كلها، أو المافيا إذا صار عددها مساوياً للأبرياء أو أكثر.
5. من ينضم بعد بدء اللعبة يدخل **مشاهداً**. الأموات يرون كل الأدوار ولهم شات خاص لا يصل الأحياء.

## التشغيل
```bash
cd server && npm ci && npm start   # المنفذ 3000
npm test                           # محاكاة لعبة كاملة آلياً
```
- التلفاز: `http://<العنوان>:3000/tv/` — الهاتف: `http://<العنوان>:3000/play/`
- النشر: Dockerfile + render.yaml (خدمة ويب Docker على Render، فحص الصحة `/health`).

## البنية
- `server/engine.js` — محرك اللعبة الموثوق (الأدوار، الليل، النهار، التصويت، الفوز، اللاعبون الآليون) مع ضمان السرية: كل لاعب لا يصله إلا دوره ومعلوماته الخاصة.
- `server/server.js` — الغرف والكودات وWebSocket وقنوات الشات (عام / مافيا ليلاً / أموات) والمشاهدون وإعادة الاتصال برمز الجلسة.
- `public/tv/` شاشة التلفاز، `public/play/` وحدة تحكم الهاتف، `public/shared/` الاتصال والأنماط.
